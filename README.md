# Sistema Bancário

Uma aplicação de sistema bancário desenvolvida com HTML, CSS, JavaScript e Python, criada para simular operações bancárias e praticar conceitos de programação e desenvolvimento web.

## Demonstração

[Clique aqui para acessar o Sistema Bancário](https://caique-torres.github.io/Sistema_Bancario/)

[Clique aqui para visualizar o código Python](https://github.com/Caique-torres/Sistema_Bancario/blob/main/sistema_bancario.py)

## Funcionalidades

- Depósito de valores
- Saque de valores
- Consulta de saldo
- Visualização do extrato
- Registro das movimentações
- Validação de valores
- Verificação de saldo insuficiente
- Interface interativa
- Interface responsiva
- Atualização do saldo
- Registro das operações realizadas
- Visualização das movimentações
- Execução das operações diretamente pelo navegador
- Versão do sistema desenvolvida em Python

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Python

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS, JavaScript e Python, trabalhando principalmente com criação de interfaces web, estilização, responsividade, manipulação do DOM, eventos, funções, estruturas condicionais, estruturas de repetição e manipulação de dados.

O projeto também foi desenvolvido para simular um sistema bancário, permitindo realizar depósitos, saques, consultar o saldo e visualizar o extrato das movimentações realizadas.

A versão web utiliza HTML, CSS e JavaScript para criar uma interface interativa, permitindo que o usuário realize as operações diretamente pelo navegador.

O projeto também possui uma versão desenvolvida em Python, permitindo praticar a mesma lógica de um sistema bancário através do terminal.
