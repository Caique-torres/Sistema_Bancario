# Sistema Bancário

Uma aplicação de sistema bancário desenvolvida em Python, criada para simular operações bancárias básicas através do terminal.

## Demonstração

[Clique aqui para acessar o Sistema Bancário](https://github.com/Caique-torres/sistema-bancario)

## Funcionalidades

- Depósito de valores
- Saque de valores
- Consulta de saldo
- Visualização do extrato
- Registro das movimentações
- Validação de valores
- Verificação de saldo insuficiente
- Menu interativo
- Mensagens de erro
- Encerramento do sistema

## Tecnologias utilizadas

- Python

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de Python, trabalhando principalmente com variáveis, estruturas condicionais, estruturas de repetição, funções, listas, entrada de dados e manipulação de informações.

O projeto também foi desenvolvido para simular um sistema bancário, permitindo realizar depósitos, saques, consultar o saldo e visualizar o extrato das movimentações realizadas.
